# Secreto TV Shortcuts

**Quick access to essential Android TV & Google TV settings.**

Secreto TV Shortcuts is a lightweight utility designed for Android TV and Google TV devices.

It provides a clean, TV-friendly interface with quick shortcuts to useful system settings that may otherwise require navigating through multiple menus.

Developed by **Mohamed LALAH / SecretoTools**.

---

## Features

Secreto TV Shortcuts currently provides quick access to:

- Google Play Store
- Settings
- Wi-Fi
- Bluetooth / Add Accessory
- Applications
- Storage
- Display
- Sound
- Accessibility
- Developer Options
- Keyboard / Input Methods
- Language
- Date & Time
- About Device

The application uses Android system settings and available system activities to open these destinations.

No root access is required.

---

## Designed for Android TV & Google TV

The interface is designed specifically for television devices and remote-control navigation.

Features include:

- TV-friendly user interface
- D-pad / remote control navigation
- Large focusable cards
- Lightweight design
- No account required
- No root required
- No Accessibility Service required
- No Internet permission
- No advertising
- No analytics or tracking

## Device Compatibility

The application is designed for devices running:

**Android 8.0 (API 26) or newer**

It is intended for Android TV and Google TV devices.

The application has been tested on multiple real Android TV / Google TV devices, including devices from different manufacturers and Android versions.

Because Android TV manufacturers may customize their system settings, the exact destination of some shortcuts may vary between devices.

Where possible, Secreto TV Shortcuts uses fallback methods to maintain compatibility across different devices.

---

## Bluetooth

On Android 12 and newer, Android may request the Nearby Devices / Bluetooth permission when opening the Bluetooth accessory screen.

This permission is used only when required by Android to access the system Bluetooth accessory interface.

Secreto TV Shortcuts does not collect or transmit Bluetooth information.
